# Dependencies and attribution

No third-party Python packages, vendor fonts, icons or native binaries are vendored.
Python/SQLite are supplied by the user's Python installation. External zstd, ES,
findmnt, the browser and platform libraries retain their own licenses. Optional
Playwright and Chromium are test dependencies only. Vendor/API documentation was
consulted as listed in docs/SOURCES.md. Legacy fixture records were generated from
the supplied V13 prototype with synthetic source data, not from the user's disks.
